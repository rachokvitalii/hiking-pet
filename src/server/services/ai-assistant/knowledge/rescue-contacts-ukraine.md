# Контакти гірських пошуково-рятувальних підрозділів України

Тип документа: тестова база знань для асистента.
Джерело: актуальні дані з сайту рятувальників, надані користувачем.

## Правила використання для LLM

- Використовуй цей документ лише для пошуку контактів рятувальників за областю, населеним пунктом, маршрутом або найближчим гірським районом.
- Якщо користувач перебуває в небезпеці або описує надзвичайну ситуацію, радь спочатку звернутися до офіційних екстрених служб, а потім надай релевантні локальні контакти з цього документа.
- Не вигадуй контакти, адреси, імена командирів або територію відповідальності.
- Якщо потрібного регіону чи населеного пункту немає в документі, прямо скажи, що в базі знань немає відповідного контакту.
- Якщо є кілька контактів в одному регіоні, показуй найближчі за населеним пунктом або назвою району.
